So sanh VB voi MCMC (eq:sd-ratio)

Luu y: hau nghiem da duoc sap xep lai nhan trang thai theo eq:label-identification truoc khi lap ty so. Ty le mau phai hoan vi: M4: 71.1% mau bi hoan vi nhan; M3 (full-rank): 63.8% mau bi hoan vi nhan. Ty le gan 50% nghia la hau nghiem doi nhan qua lai giua cac mau (label switching), khong chi la mot phep hoan vi toan cuc -- can neu ro khi bao cao.

Ty so do lech chuan R_sd,j = sd_VB(theta_j) / sd_MCMC(theta_j) (eq:sd-ratio). Gia tri < 1 cho thay Variational Bayes danh gia thap do bat dinh hau nghiem; chi nen doc bang nay sau khi M4 dat chuan hoi tu.
